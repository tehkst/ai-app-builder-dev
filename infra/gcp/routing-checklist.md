# D2.4 Routing Checklist

Use this checklist when connecting the application runtime to a public host.

## Inputs

- APP_HOST
- SERVICE_NAME
- REGION
- TLS_POLICY
- DNS_RECORD_TYPE
- DNS_TARGET

## Checks

- runtime endpoint is available
- host value is confirmed
- DNS target is known
- certificate policy is selected
- health endpoint remains reachable
- readiness endpoint remains reachable
