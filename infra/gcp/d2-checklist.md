# D2 Checklist

## Runtime

- image location is known
- service name is confirmed
- region is confirmed
- runtime account is confirmed

## Data

- storage config is confirmed
- data user is confirmed
- data name is confirmed

## References

- app reference is confirmed
- data reference is confirmed
- model references are confirmed
- payment reference is confirmed
- mail reference is confirmed

## Access

- host is confirmed
- target is confirmed
- health path is confirmed
- readiness path is confirmed

## Final checks

- container starts
- health endpoint responds
- readiness endpoint responds
- logs are structured
