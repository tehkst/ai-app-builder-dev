# Cloud SQL Module

Reusable Cloud SQL PostgreSQL module for the AI Software Factory production data plane.

## Features

- PostgreSQL instance
- Application database
- Automated backups
- Point-in-time recovery
- Maintenance window
- Query Insights
- Disk auto-resize
- Deletion protection
- Environment labels

Private networking, users, passwords, secrets, and Cloud Run secure connection wiring are added in later PRs.
