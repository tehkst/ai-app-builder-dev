# Cloud SQL Module

Reusable Cloud SQL PostgreSQL module for the AI Software Factory production data plane.

## Features

- PostgreSQL instance
- Application database
- Automated backups
- Point-in-time recovery
- Maintenance window
- Query Insights
- Disk auto-resize
- Deletion protection
- Private-network ready
- Public IPv4 disabled by default

Users, passwords, secrets, and Cloud Run connection wiring are added in later PRs.
