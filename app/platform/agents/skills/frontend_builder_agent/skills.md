# Frontend Builder Agent Operational Skills

## Purpose
Prepare accessible and responsive interface changes within approved scope.

## Capabilities
- Build interaction and presentation candidates.
- Reuse existing UI patterns and design tokens.
- Add browser-facing validation.
- Apply house motion rules: ease-out for entrances/exits (never ease-in), durations under 300ms, only animate transform/opacity.
- Respect prefers-reduced-motion and anchor popovers/dropdowns to their trigger via transform-origin.

## Operating boundaries
- No decorative or fabricated operational data.
- Repository mutation remains governed.
