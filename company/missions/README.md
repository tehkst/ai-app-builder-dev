# Missions

Missions are approved company work items.

A mission is not the same as an idea. Ideas go through discovery, proposal, and approval before becoming missions.

## Subdirectories

- `backlog/` — approved but not yet scheduled missions
- `active/` — currently running missions
- `completed/` — finished missions with outcomes and lessons

## Principle

Nothing important happens in AI Software Factory unless it belongs to a mission.
