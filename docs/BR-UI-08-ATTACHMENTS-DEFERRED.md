# Attachment Support Deferred

The Founder requested attachment support as part of the Board Room direction. It is intentionally deferred from BR-UI-08 because attachment support is not visual-only.

Attachment support should include:

- file picker
- drag and drop
- image previews
- document chips
- upload validation
- size limits
- context ingestion
- prompt binding

Recommended next mission: BR-CTX-01 Board Room Context Attachments.
