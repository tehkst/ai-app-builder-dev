# BR-UI-08 Validation

## Scope

Visual/UI-only polish for the Board Room Executive Workspace.

## Acceptance checks

1. Login still works.
2. Board Room opens inline.
3. Founder and Board Room messages are displayed in one conversation timeline.
4. Copy action is visually lighter and aligned below the message.
5. Message width is constrained for readability.
6. Markdown headings and code remain readable.
7. Composer remains fixed at the bottom of the Board Room panel.
8. Executive Brief remains in the right rail.
9. History drawer still opens.
10. Creating an engineering proposal still calls the existing workflow endpoint.

## Out of scope

- Attachments
- File upload API
- Backend changes
- Auth/login/session changes
- GitHub Executor changes
- Deployment config changes
