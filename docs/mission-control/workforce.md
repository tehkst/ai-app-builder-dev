# AI Workforce

AI Workforce is the Mission Control capability for managing the operating employees of AI Software Factory.

## Initial model

Each employee has:

- Employee ID
- Name
- Role
- Department
- Manager
- Mission
- Status
- Skills
- KPIs

## Initial departments

- Executive Office
- Engineering Command
- Launch Center
- Knowledge Vault
- Finance

## Purpose

This capability turns agents into an operating company structure. Future PRs will add a live route, persistence, performance history, assignments, and mission planning.
