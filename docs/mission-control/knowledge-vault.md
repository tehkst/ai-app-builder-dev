# Knowledge Vault

Knowledge Vault is the institutional memory system for AI Software Factory.

## Initial memory categories

- Company DNA
- Runbooks
- Architecture
- Lessons learned
- Operating policy

## Purpose

The Knowledge Vault prevents the company from operating as a long chat thread. It gives AI employees structured memory for decisions, deployment lessons, runbooks, and operating policies.

## Next capabilities

- Live API route
- Persistent storage
- Search
- ADR capture
- PRD capture
- Incident history
- Customer history
- Retrieval for AI employees
